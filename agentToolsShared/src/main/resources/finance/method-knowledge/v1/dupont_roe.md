# 扣非净资产收益率与杜邦分解

## 解释

扣非净资产收益率（roe_dt）与杜邦三组件——销售净利率（netprofit_margin）、总资产周转率（assets_turn）、权益乘数（assets_to_eqt）——直接采用财务指标接口（fina_indicator）最新报告期数值。三组件乘积作为杜邦核对值（机械恒等式 ROE ≈ 净利率 × 周转 × 权益乘数），四值齐全时附带一致性检查：与扣非 ROE 相对偏差不超过 5% 或绝对偏差不超过 0.5 个百分点视为一致，仅为核对、不做业务判断。各值无值时对应输出缺省。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，停牌缺口由调用方在回答中写明；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔由调用方在回答中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，实际采用的日期由调用方在回答中写明；
4. 历史窗口不足（如上市不足五年）时不产出记录（单输出方法无返回值、多输出方法返回空），调用方换较短窗口重试。

以上四条与缺数据提示都不随输出记录冻结或持久化：方法返回的提示通道由调用方读取后写进回答，记录本身只带数值、单位与参数。

## 反例

- 把杜邦核对值的偏差当成财务造假信号：一致性检查只是机械核对，偏差来源包括口径差异与非经常项目。
- 混用报告期：四个值必须同一报告期，取数时对齐最新 end_date。
- 把扣非 ROE 与未扣非 ROE 直接比较。

## 来源讨论

杜邦分析把净资产收益率分解为盈利、周转、杠杆三个驱动，是经典财务分析框架；「杜邦三组件」分解式对净利率与周转的乘积近似总资产收益率再乘权益乘数，接口各字段口径以 TuShare 财务指标文档为准。

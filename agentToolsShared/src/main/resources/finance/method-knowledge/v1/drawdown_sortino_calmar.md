# 最大回撤与Sortino与Calmar

## 解释

价格序列 P 的三个风险指标：最大回撤 = 区间内 P/历史峰值 − 1 的最小值（非正）；Sortino 与既有夏普比率同一套超额收益定义（周期收益减周期无风险利率，年化利率按每年期数折算），下行偏差只统计负超额项的样本标准差（ddof=1），比率年化；Calmar = 区间复合收益（CAGR 口径）/ 绝对最大回撤。负超额不足两期不输出 Sortino；区间无回撤（maxDD=0）不输出 Calmar。股票与 ETF 用复权收盘（可传复权因子序列由方法内相乘，缺因子日与无行情日分开跳过），指数用收盘、公募用累计净值（不传因子）。序列按日期升序传入。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，停牌缺口由调用方在回答中写明；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔由调用方在回答中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，实际采用的日期由调用方在回答中写明；
4. 历史窗口不足（如上市不足五年）时不产出记录（单输出方法无返回值、多输出方法返回空），调用方换较短窗口重试。

以上四条与缺数据提示都不随输出记录冻结或持久化：方法返回的提示通道由调用方读取后写进回答，记录本身只带数值、单位与参数。

## 反例

- 把最大回撤当年度指标却不注明区间：回撤依赖起止点。
- 无负超额时强行输出 Sortino：下行偏差无定义。
- 用未复权价格算股票回撤：除权跳空会虚增回撤。
- 缺复权因子日按 1.0 处理：本方法跳过并单独计数。

## 来源讨论

最大回撤刻画最坏路径损失，是资管风控与 MAR 比率的分母来源；Sortino（Sortino-Price 1994）只惩罚下行波动，与夏普的区别在于上行波动不进分母；Calmar（Young 1991）以年化收益除以最大回撤，衡量单位回撤换取的收益。

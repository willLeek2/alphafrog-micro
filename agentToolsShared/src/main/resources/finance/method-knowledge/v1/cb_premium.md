# 可转债转股与纯债溢价率

## 解释

转股溢价率（cb_over_rate）与纯债溢价率（bond_over_rate）直接采用可转债日线接口在目标交易日的百分比数值；无值的键不输出。转股溢价率衡量转债价格相对转股价值的贵贱，纯债溢价率衡量相对债底的贵贱。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，输出附带窗口内停牌缺多少个交易日；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔在输出中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，输出注明实际采用的日期；
4. 历史窗口不足（如上市不足五年）时按可得窗口计算并标注。

## 反例

- 把两个溢价率的缺值当 0。
- 单独用转股溢价率判断「贵」：低转股溢价可能伴随高纯债溢价，需两者并看。

## 来源讨论

转债定价的「债底 + 期权」二叉口径：纯债溢价对应债性部分偏离，转股溢价对应股性部分偏离，两者一起刻画转债在股债之间的位置；接口已给出计算结果，直接采用。

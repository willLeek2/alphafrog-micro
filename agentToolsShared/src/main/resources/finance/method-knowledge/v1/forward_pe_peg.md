# 预测市盈率与PEG

## 解释

输入为券商盈利预测（report_rc）行列表，每行含机构名（org_name）、预测期（quarter）、市盈率（pe）、每股收益（eps），无值字段传 null（不当 0）。方法内配对规则：按机构分组、组内按预测期排序（数据接口不保证行序，方法必须自行排序，也禁止取返回列表第一行）；「同一机构、相邻预测期、当期市盈率与每股收益同行」——当期行提供预测市盈率与本期每股收益，紧邻前期行提供上期每股收益，增速 g = 本期/上期 − 1，PEG = 预测市盈率/(g×100)。跨机构的有限预测市盈率与 PEG 各取中位数。只有单期预测、或算不出有限正增速时，只输出预测市盈率。同一机构同一预测期多行时取列表最后一行，调用前建议按发布日期去重留最新。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，停牌缺口由调用方在回答中写明；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔由调用方在回答中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，实际采用的日期由调用方在回答中写明；
4. 历史窗口不足（如上市不足五年）时不产出记录（单输出方法无返回值、多输出方法返回空），调用方换较短窗口重试。

以上四条与缺数据提示都不随输出记录冻结或持久化：方法返回的提示通道由调用方读取后写进回答，记录本身只带数值、单位与参数。

## 反例

- 把不同机构、不同预测期的市盈率与增速硬配成一个 PEG：分子分母必须同源同行。
- 增速为负或为零时强行算 PEG：此时 PEG 无意义，只输出预测市盈率。
- 取返回列表第一行当「最新预测」：接口不保证行序。
- 用单一机构的预测代表全市场共识：本方法取跨机构中位数。

## 来源讨论

PEG 把预测市盈率与盈利增速匹配，出自 Lynch 的成长股框架（市盈率约等于增速时视为合理）；跨机构取中位数是为降低单一卖方偏差，中位数对离群预测更稳健。

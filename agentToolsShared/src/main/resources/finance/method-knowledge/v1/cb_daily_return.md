# 可转债日收益与区间收益

## 解释

日收益 = 当日涨跌幅（pct_chg）/100；区间收益 = 区间内日收益连乘减一（prod(1+ret_d) − 1）。双输出：最后一个有值日的日收益，与区间连乘收益（window 不传对整个传入序列连乘，传入时对最后 window 个有值日连乘）。转债价格序列不做复权处理（转债无复权因子概念，强赎与转股价调整不属于本方法处理范围）。序列按日期升序传入；缺值日跳过并计入警告。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，停牌缺口由调用方在回答中写明；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔由调用方在回答中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，实际采用的日期由调用方在回答中写明；
4. 历史窗口不足（如上市不足五年）时不产出记录（单输出方法无返回值、多输出方法返回空），调用方换较短窗口重试。

以上四条与缺数据提示都不随输出记录冻结或持久化：方法返回的提示通道由调用方读取后写进回答，记录本身只带数值、单位与参数。

## 反例

- 把涨跌幅当小数（0.01）与百分比（1.0）混用：本方法约定传入百分比数值。
- 跨停牌段连乘时不说明间隔。
- 用收盘价自算日收益却不核对与 pct_chg 的口径一致性（接口同日两者应一致）。

## 来源讨论

区间收益按日收益几何连乘（复合口径），与单日简单收益不同；转债 T+0 与无涨跌停（沪深新规下 20%/30% 机制）特性使其日收益分布与股票不同，本方法只负责计算不做判断。

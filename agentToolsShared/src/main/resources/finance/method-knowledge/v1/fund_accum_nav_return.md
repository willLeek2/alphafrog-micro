# 公募累计净值区间收益

## 解释

用累计净值（不是单位净值）计算区间收益：累计净值[t]/累计净值[t−N] − 1。累计净值把历史分红加回，是可比的净值口径；单位净值分红日会跳降，不能直接算收益。window 不传时按传入序列首尾计算——数据集复用命中时必须先按请求窗口用 nav_date 过滤、按日期排序再取首尾（超集复用下直接拿文件首尾会超出请求窗口）；传入 window 时取最后 N+1 个有效净值日两端。未披露净值日（null）跳过并计入警告。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，输出附带窗口内停牌缺多少个交易日；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔在输出中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，输出注明实际采用的日期；
4. 历史窗口不足（如上市不足五年）时按可得窗口计算并标注。

## 反例

- 用单位净值算区间收益：分红日跳降会把分红算成亏损。
- 复用命中数据集时不过滤请求窗口直接取文件首尾。
- 混用不同份额类别（A/C 份额）的净值序列。

## 来源讨论

累计净值口径在基金评价中用于还原全收益，GIPS 与国内基金评价实务（如晨星口径）均以分红再投资为默认；接口的 accum_nav 即该口径。

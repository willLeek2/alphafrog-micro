# 股息率

## 解释

股息率采用每日指标接口（daily_basic）的近十二个月股息率 dv_ttm，接口已是百分比数值，展示与计算均不再乘 100；无值不输出记录。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，输出附带窗口内停牌缺多少个交易日；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔在输出中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，输出注明实际采用的日期；
4. 历史窗口不足（如上市不足五年）时按可得窗口计算并标注。

## 反例

- 把未分红年份的缺值当 0% 处理：缺值与零股息是两件事。
- 用单年分红除以当前价冒充滚动十二个月口径。

## 来源讨论

股息率按近十二个月滚动口径（dv_ttm）衡量现金分红回报，与债息直观可比；接口已折算，直接采用。

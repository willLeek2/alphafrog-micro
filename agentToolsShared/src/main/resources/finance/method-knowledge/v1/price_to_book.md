# 市净率

## 解释

市净率直接采用每日指标接口（daily_basic）在目标交易日的 pb 值，不再加工。净资产为负或缺失时接口留空，本方法无值不输出记录。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，输出附带窗口内停牌缺多少个交易日；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔在输出中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，输出注明实际采用的日期；
4. 历史窗口不足（如上市不足五年）时按可得窗口计算并标注。

## 反例

- 净资产为负（资不抵债）时把缺值当 0 或当极低估值使用。
- 直接比较不同会计准则下的市净率而不注明口径。

## 来源讨论

市净率是价格除以每股净资产，Fama-French 三因子模型中 HML 因子即基于账面市值比构建；接口值已是统一口径，直接采用。

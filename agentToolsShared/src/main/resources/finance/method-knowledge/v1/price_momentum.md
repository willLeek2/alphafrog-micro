# 价格动量

## 解释

价格动量 = 复权收盘[t]/复权收盘[t−N] − 1，N 取 63/126/252（约 3/6/12 个月，按交易日历）。股票需复权口径：传入收盘与等长复权因子序列时方法内相乘（adj_close = close × adj_factor）；不传因子表示序列已是复权口径（指数收盘即用）。缺因子日（灌数缺口）与无行情日（停牌口径）分开计数并跳过，缺因子不当 1.0；有效日不足 N+1 时不产出记录，调用方换较短窗口重试。序列按日期升序传入；数据集复用命中时先按请求窗口过滤再传入。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，停牌缺口由调用方在回答中写明；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔由调用方在回答中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，实际采用的日期由调用方在回答中写明；
4. 历史窗口不足（如上市不足五年）时不产出记录（单输出方法无返回值、多输出方法返回空），调用方换较短窗口重试。

以上四条与缺数据提示都不随输出记录冻结或持久化：方法返回的提示通道由调用方读取后写进回答，记录本身只带数值、单位与参数。

## 反例

- 用未复权收盘算长期动量：除权除息会造成跳空，动量被分红拆股污染。
- 把缺复权因子的日期按因子 1.0 处理：本方法跳过并单独计数。
- 停牌日计入窗口天数：窗口按实际有行情的交易日计。

## 来源讨论

动量效应是实证资产定价中最稳健的异象之一（Jegadeesh-Titman 1993）；月度动量通常用 12 个月减最近 1 个月，第一轮按 3/6/12 个月窗口两端比较实现，不做去最近月 refinements。

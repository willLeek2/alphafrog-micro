# 年化波动率

## 解释

年化波动率回答的问题是：一组周期收益率的离散程度，换算成年度口径后是多少。计算分两步：先取收益率序列的样本标准差（自由度修正 ddof 固定为 1），再乘以每年期数的平方根。平方根换算来自"独立同分布下方差随时间线性增长"的假设。

输入是收益率序列本身，方法不获取数据，也不判断收益率的频率含义；每年期数由调用方按数据频率显式给出（日频常取 252）。可选的 window 表示只用序列末尾的 window 个收益率，缺省使用全样本。

## 反例

- 把价格序列直接当收益率传入是错误的；应先用相邻价格算出周期收益率。
- 用总体标准差（ddof=0）会低估波动；本方法固定使用样本标准差（ddof=1）。
- 年化因子乘错（例如日频数据乘 252 而不是它的平方根）会把结果放大约 15.9 倍。
- 序列只有一个点时样本标准差没有定义；序列长度至少为 2。
- window 大于序列长度没有含义；调用方应先确认序列足够长。

## 来源讨论

"标准差乘以期数平方根"的年化方式是风险管理教材中的标准做法，常见于 Jorion 的 VaR 教材和 CFA 课程的风险章节。本方法把 ddof 固定为 1 并写进约定，是因为金融收益率样本通常按样本标准差报告；把自由度做成方法级约定而非逐次参数，可以减少同一指标在不同调用间口径漂移。window 参数只截取末尾子序列，不做滚动窗口序列输出——需要滚动波动率序列时应另立方法，不在本版本扩展。

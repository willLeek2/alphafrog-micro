# 滚动市盈率与历史分位

## 解释

滚动市盈率取股票日线估值序列最后一个有值日的市盈率（TTM）；盈利收益率（E/P）为其倒数；历史分位是窗口内有值日中不高于当前值的占比（0~1，含当日），窗口默认整个传入序列、可显式指定回看的有值交易日个数。亏损（接口留空）或当前值非正时，只输出市盈率本身，不输出倒数与分位。序列由取数工具（getStockDaily 估值可选列）取得后按日期升序传入，null 日跳过。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，停牌缺口由调用方在回答中写明；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔由调用方在回答中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，实际采用的日期由调用方在回答中写明；
4. 历史窗口不足（如上市不足五年）时不产出记录（单输出方法无返回值、多输出方法返回空），调用方换较短窗口重试。

以上四条与缺数据提示都不随输出记录冻结或持久化：方法返回的提示通道由调用方读取后写进回答，记录本身只带数值、单位与参数。

## 反例

- 把亏损时的负市盈率当「低估」使用：本方法对非正市盈率不输出 E/P 与分位。
- 历史分位跨市场或跨行业比较：分位只在同一标的自身历史上有意义。
- 用不同回看窗口的分位直接比较而不注明窗口长度。

## 来源讨论

E/P 即盈利收益率，是市盈率的倒数口径，价值投资文献（Graham-Dodd 传统）常用其与债券收益率对比；历史分位是滚动窗口内的经验分布位置，不是估值理论值。亏损期市盈率无经济含义，故留空而非取负。

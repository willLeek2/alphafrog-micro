# ETF复权区间收益

## 解释

ETF 复权区间收益 = 复权收盘[t]/复权收盘[t−N] − 1，复权口径为 ETF 收盘乘复权因子（可传因子序列由方法内相乘，或预先乘好传入）。window 不传时按传入序列首尾计算——数据集复用命中时文件覆盖可能宽于请求窗口，调用侧必须先按请求窗口过滤、按日期排序后再传入；传入 window 时取最后 N+1 个有效日两端。缺因子日与无行情日分开跳过。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，停牌缺口由调用方在回答中写明；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔由调用方在回答中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，实际采用的日期由调用方在回答中写明；
4. 历史窗口不足（如上市不足五年）时不产出记录（单输出方法无返回值、多输出方法返回空），调用方换较短窗口重试。

以上四条与缺数据提示都不随输出记录冻结或持久化：方法返回的提示通道由调用方读取后写进回答，记录本身只带数值、单位与参数。

## 反例

- 用未复权净值或收盘算区间收益：分红会造成收益低估。
- 数据集复用命中时直接拿整段文件首尾：覆盖区间可能宽于请求窗口，必须先过滤。
- 把停牌日计入窗口。

## 来源讨论

区间收益按两端相除的简单收益口径，与复权因子配合还原分红再投资；不采用对数收益，与既有方法族的简单收益口径一致。

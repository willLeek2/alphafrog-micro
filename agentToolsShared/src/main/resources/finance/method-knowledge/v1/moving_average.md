# 移动平均线

## 解释

简单移动平均（SMA）为最近 N 个有效日的复权收盘均值；指数移动平均（EMA）以首个 N 日 SMA 为起点、α = 2/(N+1) 迭代到最新值。一次调用一个窗口，双输出（SMA 与 EMA）。股票需复权口径（可传复权因子序列由方法内相乘，或预先乘好传入；指数收盘即用，ETF 乘复权因子）。缺因子日与无行情日分开跳过；「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算。序列按日期升序传入。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，停牌缺口由调用方在回答中写明；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔由调用方在回答中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，实际采用的日期由调用方在回答中写明；
4. 历史窗口不足（如上市不足五年）时不产出记录（单输出方法无返回值、多输出方法返回空），调用方换较短窗口重试。

以上四条与缺数据提示都不随输出记录冻结或持久化：方法返回的提示通道由调用方读取后写进回答，记录本身只带数值、单位与参数。

## 反例

- 用未复权收盘算长期均线：除权跳空让均线失真。
- 停牌日计入窗口：按实际有行情的交易日计。
- 把 EMA 与 SMA 的滞后差异当成信号：两者只是平滑权重不同。

## 来源讨论

SMA 等权平滑、EMA 指数衰减加权，均为技术分析的基础平滑器；EMA 以首窗口 SMA 为种子是常见工程实现，消除起点敏感性；常用窗口 50/200 日（金叉死叉框架）或周线 10/40。

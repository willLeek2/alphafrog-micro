# 自由流通换手率

## 解释

自由流通换手率采用每日指标接口（daily_basic）的 turnover_rate_f，接口已是百分比数值；无值不输出记录。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，输出附带窗口内停牌缺多少个交易日；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔在输出中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，输出注明实际采用的日期；
4. 历史窗口不足（如上市不足五年）时按可得窗口计算并标注。

## 反例

- 与按总股本口径的换手率（turnover_rate）混用比较。
- 用单日换手率推断长期流动性而不注明区间。

## 来源讨论

自由流通换手率以剔除限售与战略持股后的自由流通股本为分母，衡量实际可交易筹码的活跃度，比总股本口径更贴近交易行为。

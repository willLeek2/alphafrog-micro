# 指数滚动市盈率与市净率

## 解释

指数滚动市盈率与市净率直接采用指数每日指标接口（index_dailybasic）在目标交易日的 pe_ttm 与 pb 值，无值的键不输出。数据面以接口实际覆盖的指数为准（该接口口径为大盘指数，覆盖范围以抓取实测为准），经 getIndexDaily 估值可选列取得。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，输出附带窗口内停牌缺多少个交易日；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔在输出中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，输出注明实际采用的日期；
4. 历史窗口不足（如上市不足五年）时按可得窗口计算并标注。

## 反例

- 对接口未覆盖的指数强行给出估值：无值键不输出，不要拿个股估值聚合冒充。
- 忽略指数市盈率口径（总股本加权等）与个股加总口径的差异。

## 来源讨论

指数估值用指数编制方公布的每日指标，避免用成分股聚合产生口径偏差；本方法不做任何加工，保持与数据源一致。

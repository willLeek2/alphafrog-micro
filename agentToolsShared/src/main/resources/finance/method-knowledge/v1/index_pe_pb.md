# 指数滚动市盈率与市净率

## 解释

指数滚动市盈率与市净率直接采用指数每日指标接口（index_dailybasic）在目标交易日的 pe_ttm 与 pb 值，无值的键不输出；非正（无效比率）的 pb 只省略 pb 键，pe_ttm 照常输出。数据面以接口实际覆盖的指数为准，2026-09-29 生产实测：按单个交易日请求该接口返回 15 只指数（含 000300.SH 沪深300、000688.SH 科创50、000852.SH 中证1000），历史回灌得 64623 行、覆盖 2005-01-04 至 2026-08-28；调用方经 getIndexDaily 估值可选列取得。

缺数据与停牌口径（四条）：
1. 窗口类指标按标的实际有行情的交易日取数，停牌日不算进窗口，停牌缺口由调用方在回答中写明；
2. 「连续 N 个交易日」落实为最近 N 个有行情的交易日，跨停牌段照常计算，停牌造成的间隔由调用方在回答中说明；
3. 问「今天」而当日无行情（尚未抓到或当日停牌）时改用最近一个有行情的交易日，实际采用的日期由调用方在回答中写明；
4. 历史窗口不足（如上市不足五年）时不产出记录（单输出方法无返回值、多输出方法返回空），调用方换较短窗口重试。

以上四条与缺数据提示都不随输出记录冻结或持久化：方法返回的提示通道由调用方读取后写进回答，记录本身只带数值、单位与参数。

## 反例

- 对接口未覆盖的指数强行给出估值：无值键不输出，不要拿个股估值聚合冒充。
- 忽略指数市盈率口径（总股本加权等）与个股加总口径的差异。

## 来源讨论

指数估值用指数编制方公布的每日指标，避免用成分股聚合产生口径偏差；本方法不做任何加工，保持与数据源一致。

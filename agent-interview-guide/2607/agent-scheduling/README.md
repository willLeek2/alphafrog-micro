# 智能体长工具等待与可恢复调度：阅读导航

这组教程围绕同一个问题展开：一次智能体运行调用耗时较长的 Python 沙箱任务时，怎样先保存执行现场、归还 Java 工作线程，等沙箱结束后再由另一条工作线程接着执行。

如果你几乎没有读过这套代码，先阅读 [10-Agent长工具等待与可恢复调度.md](./10-Agent长工具等待与可恢复调度.md)。它只选择八个文件，借助一个完整示例讲清调用顺序。阅读时不需要先认识全部类。

阅读完入门篇后，再按下面顺序阅读详细版。详细版覆盖本专题的 39 个 Java 与 XML 文件。每个文件都有独立讲解，包括存在原因、阅读入口、重要字段或方法、在示例中的动作、失败后的处理以及它交给下一个文件的事实。

# Java GC 校招场景题

这组材料面向 Java 后端校招与实习面试，重点回答两个问题：面试官怎样询问 GC 排查，以及没有生产 GC 事故经历时，怎样诚实地把 AlphaFrog 的潜在风险讲清楚。

- [10-校招面经与回答模板.md](./10-校招面经与回答模板.md)：主体资料，包含 17 组基础问题的主回答与连续追问回答、通用排查回答和 18 道场景题。
- [20-AlphaFrog潜在GC场景.md](./20-AlphaFrog潜在GC场景.md)：项目补充，明确属于风险分析练习，不冒充真实故障经历。
- [90-来源与检索记录.md](./90-来源与检索记录.md)：面经证据、官方资料、检索方法和使用限制。

建议先逐题练习基础问题的“可直接回答”和“追问回答”，再练习两分钟排查回答与场景题。项目补充适合在面试官要求结合简历时使用。
